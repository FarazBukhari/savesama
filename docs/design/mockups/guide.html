Set up on this phone

About five minutes, once. After that SaveSama starts saving whenever the server is running.

  1. Install Termux
    Get it from F-Droid. The Play Store version is outdated and won't work.
    Open F-Droid
  2. Install the tools
    pkg update -y && pkg install -y python ffmpeg git
  3. Install the SaveSama server
    pip install "git+https://github.com/FarazBukhari/savesama#subdirectory=server"
  4. Start it
    It shows a QR code and opens SaveSama to pair. Leave Termux running.
    savesama
  5. Keep it awake
    In Android settings, set Termux's battery use to Unrestricted. In the Termux notification, tap Acquire wakelock.
